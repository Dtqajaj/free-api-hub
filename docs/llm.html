免费 LLM 怎么用

从零到跑通 10 分钟 · 连不上？先看第四节对照表

一、30 秒跑通（推荐这条路）

国内直连、免翻墙、永久免费、注册不用绑卡。智谱 GLM-4-Flash。

1注册拿 key

打开 open.bigmodel.cn → 手机号注册 → API Keys → 新建 → 复制那串 key（形如 xxxxxxxx.xxxxxxxx，中间有个点，别漏）。

2curl 直接测
curl https://open.bigmodel.cn/api/paas/v4/chat/completions \
  -H "Authorization: Bearer 你的KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"glm-4-flash","messages":[{"role":"user","content":"说个笑话"}]}'

返回里有 choices[0].message.content 就是通了。报 401 是 key 错，400 是模型名写错。

3Python 用起来
export ZHIPU_KEY=你的KEY
python3 tools/llm.py "写一句诗" zhipu

或者代码里：

from llm import chat
print(chat("写一句诗", platform="zhipu"))

所有这些平台都能用同一个 OpenAI 客户端，只改 base_url、key、model 三个值。

Python OpenAI SDK

from openai import OpenAI

client = OpenAI(
    api_key="你的KEY",
    base_url="https://open.bigmodel.cn/api/paas/v4",
)
r = client.chat.completions.create(
    model="glm-4-flash",
    messages=[{"role": "user", "content": "你好"}],
)
print(r.choices[0].message.content)

不装任何包（纯标准库）

import json, urllib.request

req = urllib.request.Request(
    "https://open.bigmodel.cn/api/paas/v4/chat/completions",
    data=json.dumps({
        "model": "glm-4-flash",
        "messages": [{"role": "user", "content": "你好"}],
    }).encode(),
    headers={
        "Content-Type": "application/json",
        "Authorization": "Bearer 你的KEY",
    },
)
with urllib.request.urlopen(req, timeout=60) as r:
    print(json.load(r)["choices"][0]["message"]["content"])

四、连不上？按错误码对症下药

409 / ConnectTimeout / 请求一直转圈 / getaddrinfo failed
不是 key 的问题，是网络到不了。你选了需要代理的那几家（Google / Groq / OpenRouter / Cerebras / Mistral）。 换国内直连的那四家，或者开代理。先跑诊断确认： 
python3 tools/llm-test.py
401 Unauthorized
key 错了。三个高频原因：
① key 前后带了空格或换行
② 智谱的 key 中间有个 .，复制时漏了
③ 请求头写成 Authorization: 你的KEY，少了 Bearer
404 Not Found
base_url 路径错了。最常见：直接把 https://api.xxx.com 当 base_url，少了 /v1。
也可能是模型名写错 —— 模型名必须一字不差，大小写敏感，带斜杠的（Qwen/Qwen2.5-7B-Instruct）不能漏前缀。
400 Bad Request
多半是模型名不存在。看一眼返回体的 message 字段，会直接告诉你哪个模型不存在。
429 Too Many Requests
限速或当日额度用完。免费层的限速都很低（Groq 约 30 req/min），加 time.sleep(2) 或换平台轮询。
402 / Insufficient Balance
余额不足。DeepSeek 属于这种（它不是免费，是便宜）。

五、一键诊断

不确定卡在哪一环，跑这个，它会按 网络 → 路由 → 鉴权 → 推理 四层逐层告诉你断在哪。

# 只测网络（不需要 key）
python3 tools/llm-test.py

# 带 key 全测
python3 tools/llm-test.py --key 你的KEY --all

# 只测某一家
python3 tools/llm-test.py --id zhipu --key 你的KEY
